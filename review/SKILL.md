Use a subagent to review the change. Only include enough info for the subagent to understand the context. Focus on correctness, edge cases, potential bugs, security, code cleanliness, and dead code. Do not need to pass changes to subagent, it can use git to figure out the changes.

Discuss the findings and approaches to fix them first before changing the code.
